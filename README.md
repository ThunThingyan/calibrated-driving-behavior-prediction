# Calibrated Early Prediction of Driving Behavior

This project investigates the early prediction of ego-vehicle driving behaviour from dashcam video in dense Indian traffic. The proposed framework predicts upcoming **slowdown and deviation events** at different time-to-event horizons while estimating and calibrating prediction confidence.

## Objectives
- Predict driving behaviour before an event occurs.
- Analyse performance across different time-to-event horizons.
- Evaluate prediction confidence and calibration.
- Study reliable early prediction for intelligent transportation systems.

## Technologies
Python, PyTorch, OpenCV, NumPy, Pandas, Scikit-learn, Matplotlib, Jupyter/Kaggle.

## Dataset
Indian driving video data with dense and heterogeneous traffic scenarios. Raw dataset files are not included in this repository.

## Evaluation
Accuracy, Precision, Recall, F1-score, AUROC, ECE, Brier Score, and reliability analysis.
